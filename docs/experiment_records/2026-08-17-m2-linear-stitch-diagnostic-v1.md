## 4. 解读（判定规则的直接推论）

1. **v7 的剩余差距不是线性的**：蒸馏已把骨干特征贴到 B0 的 99.8% 余弦邻域，最深 stage 恒等误差仅 0.0034，线性映射只能再消 1%。行人核心 2/5 的发丝级失败（0.03–0.05%）藏在**非线性残差**里——缝合层（v8c）在数学上够不着它；
2. **v5 的几何分量真实存在但不足**：线性可消 35–47%（未过 50% 门槛），且 v5 的病本在刻度偏移（v6 已证），几何修正治不了校准；
3. 按 v8 协议 §3：v8c（冻结骨干+线性缝合层）**降级**；下一优先方向为 **v8b（BCT 式功能蒸馏：梯度穿过冻结完整 B0 下游栈，在语义语料上匹配 B0 最终输出）**——它直接优化下游功能行为而非中间几何，正对 v7 残差的非线性本质；v8d（残差注入）备选。
