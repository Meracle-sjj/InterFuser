# M2 视觉负迁移修复 Probes 记录

## 1. 数据与根因起点

原V使用全部7,590个基础普通语义样本并增加4,317个行人危险样本，不是纯行人训练。危险增强模型在原冻结语义validation上相对基础inverse-sqrt模型将mIoU从0.46324提高到0.48675，行人IoU从0.05667提高到0.12047，且道路、车辆、交通灯等多数类别同时改善。因此“普通帧不足导致语义预训练阶段直接遗忘”不符合现有证据；主要负迁移发生在独立语义骨干替换作者驾驶骨干之后。

## 2. 最终模型权重插值

| Probe | Manifest SHA-256 | 结论 |
| --- | --- | --- |
| 全模型浮点插值 α=0.25/0.5/0.75 | `ca5448f1998559f6df755f46fa04b6399b4021113b7258945e909ec46c949f34` | 0/3通过；α0.25非行人最坏退化159.29% |
| 仅RGB浮点插值，保留B0下游状态 | `bd85e105229abbc3dc92ab95796c4b92407ef29516cda183b34c16587f182e30` | 0/3通过；α0.25非行人最坏退化191.08% |

两次结果证明B0/V不在可直接线性连接的低损失盆地；增加alpha密度无依据。

## 3. B0 锚定分阶段语义适配

从作者B0的330个RGB张量初始化，头部warmup一轮，随后骨干/头部学习率=`1e-5/1e-4`。语义best epoch3：mIoU 0.47315、行人IoU 0.10720、交通灯IoU 0.18881，330张量严格导出，全部语义门禁通过。

零微调回接manifest SHA-256为 `cec3e2a25d7f8d050634a3e29e057b0f2992d274ccab09fb0f980bc82b10084e`。相对同一作者B0，行人AP/AUC/IoU改善15.00%/0.48%/11.05%，整体traffic最坏退化2.14%；但非行人IoU退化5.64%，行人waypoint时序残差退化12.27%，未通过3%/10%保持门禁。

## 4. L2-SP 与状态漂移分解

系数1e-5的L2-SP语义manifest SHA-256为 `0c674e113efc786141a8ee77edc4c60e21564eb956d2b718ddc33a140ef52cc7`，best mIoU 0.47267。训练末期未加权参数惩罚9.80、加权项约`9.8e-5`，没有形成足够保持作用。

逐状态分解揭示：无L2-SP候选相对B0的卷积/BN affine参数漂移平方和仅4.90，而BN running mean/variance漂移24,587.05；L2-SP候选对应4.89/24,579.38。绝大部分状态漂移来自不可训练的BN缓冲，参数L2-SP无法直接约束。

## 5. 冻结 B0 BatchNorm 统计

冻结BN running statistics、其余数据/日程不变。语义manifest SHA-256为 `5ae9bc7ed96980a055d4b1a53e2b71378bdfcbed7eb57f489b1439fe8864a882`；best epoch3 mIoU 0.47866、行人IoU 0.08156、交通灯IoU 0.19529，严格导出330张量。相对B0的参数漂移4.90，BN统计漂移精确为0。

严格swap生成：总RGB张量330，其中165个可训练张量变化、165个BN缓冲保持；完整模型变化alias 330，非RGB哈希一致。零微调scene manifest SHA-256为 `b226ab968d2f1c970d85e0a7d51e0fe36dbf13f98359b7e92d9b2201b871df31`。

| 门禁 | 实测 | 上限/下限 | 状态 |
| --- | ---: | ---: | --- |
| 行人核心改善数 | 4/5 | ≥3 | 通过 |
| 整体traffic最坏退化 | 0.97829% | ≤3% | 通过 |
| 行人时序最坏退化 | 2.58677% | ≤10% | 通过 |
| 非行人核心最坏退化 | 3.00577% | ≤3% | **失败** |

非行人AP/AUC分别提高3.60%/1.30%，junction/red-light macro-F1提高1.91%/1.62%；唯一触发上限的是固定0.5阈值下occupied IoU下降3.00577%。虽只超过0.00577个百分点，仍按预注册精确值判失败，不四舍五入为通过。

## 6. 结论边界

冻结B0 BN统计将灾难性普通场景退化缩小为单一固定阈值IoU的边界性超限，强支持“BN域统计漂移是主要负迁移来源”。但候选仍未通过全部门禁，`stage2_admitted=false`；不运行Stage 2、test、route39或D7。

若继续，合理的下一项只剩独立预注册的概率校准诊断或B0教师特征蒸馏；不得放宽3%阈值、扫描BN动量或根据test选择方案。
