# InterFuser 视觉负迁移修复协议 v4：B0 源点 L2-SP

| 字段 | 内容 |
| --- | --- |
| 状态 | **PROBE-FROZEN：v3零微调结果后冻结单系数** |
| 配置 | `configs/thesis/semantic_pretraining_b0_anchored_l2sp_probe_v2.json` |
| L2-SP系数 | `1e-5`，只约束RGB骨干可训练参数 |

## 1. v3 证据

无L2-SP的B0锚定语义模型通过语义门禁；零微调接回后，行人AP/AUC/IoU提高15.00%/0.48%/11.05%，整体traffic最坏退化2.14%。但非行人IoU下降5.64%，行人waypoint时序残差恶化12.27%，超过冻结的3%/10%上限，不能进入Stage 2。

该结果证明B0源点方向有效，但五轮适配仍稍微离开原驾驶表征。候选骨干相对B0参数漂移平方和为24,591.95；系数 `1e-5` 在该漂移量级对应约0.246的惩罚，与语义任务损失同量级。

## 2. 唯一变化

数据、类别权重、B0初始化、头部warmup一轮、骨干/头部学习率、五轮预算和best-mIoU选择全部继承v3。唯一变化是在训练阶段加入：`Lsemantic + 1e-5 * Σ||θrgb−θB0||²`。reference在训练开始时从B0初始化精确冻结；validation不计正则项。

只运行该单一系数，不根据结果继续扫描。语义准入沿用mIoU≥0.46324、行人IoU≥0.08、交通灯IoU≥0.15和330张量严格导出；通过后复用v3相同零微调scene门禁。

## 3. 停止条件

- 语义门禁失败：L2-SP过强或任务不兼容，停止；
- 零微调仍不满足非行人3%和时序10%保持：不进入Stage 2，转向显式B0教师特征蒸馏；
- 通过：才准入一次三轮Stage 2，并保持test冻结。
